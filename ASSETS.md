# Artwork and theme

This repository contains the personal profile README for **NTPhat-Dev**.

The Hatsune Miku banner and transparent chibi illustration were generated with the built-in OpenAI image generation tool for this profile. They are fan artwork, not official character artwork. Hatsune Miku belongs to the respective rights holders.

## Design prompts

- **Banner:** Wide original anime key visual of Hatsune Miku with turquoise twin tails, a coding workstation, musical notes, chibi Miku sketches, mint and pink holographic accents. Exact personal lettering: “PHÁT GIÀ”, “NTPhat-Dev”, “CODE / CREATE / MIKU”.
- **Chibi:** Transparent-background, full-body chibi Hatsune Miku hugging a laptop, with musical notes, stars and a small leek. Teal, mint, navy and pink palette; no lettering.

The buttons, toolkit, animated musical divider and outro are original SVG graphics. They contain no scripts, analytics or external dependencies.
